# Информатика для первокурсника

Краткий справочник по системам счисления. Он помогает понять позиционную запись чисел и вручную переводить значения между двоичной, десятичной и шестнадцатеричной системами.

Автор: arishe4ka

## Тема

Системы счисления и перевод чисел.

## Файлы

- `glossary.md` — основные понятия.
- `examples.md` — разобранные переводы чисел.
- `sources.md` — использованные учебные источники.
- `questions.md` — вопросы для самопроверки (добавлены в отдельной ветке).
- `.gitignore` — правила для временных файлов.

## Как пользоваться справочником

Сначала прочитайте `glossary.md`, затем разберите примеры в `examples.md`. После этого попробуйте ответить на вопросы из `questions.md`, не подглядывая в ответы. Ссылки на материалы, по которым подготовлен справочник, находятся в `sources.md`.
